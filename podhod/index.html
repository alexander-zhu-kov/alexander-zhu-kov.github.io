Как я строю системы

Сначала процесс и ответственность, потом инструмент. Программу проектирую как руководитель, который будет ею пользоваться на планёрке, и выпускаю как инженер: с автотестами, миграциями базы и защитой данных.

Как директор

Принципы, которые закладываю в систему

Каждое отклонение — действие

Недовыполнение без причины закрыть нельзя. Причина ведёт к мероприятию с ответственным и сроком, статус виден на разборе.

История, а не правка задним числом

Цели, графики, план фиксируются с датой начала действия. Прошлые периоды не пересчитываются.

Права по ролям, а не по доверию

Каждая должность видит и меняет только своё. Изменение утверждённого плана — только с причиной и в журнал.

Данные готовит система

Планёрка и отчёты строятся из того, что вносят смены. Никто не собирает цифры накануне вечером.

Внедрение пакетами

Сначала то, что даёт результат завтра: факт, причины, планёрка. Остальное — когда команда готова.

Работает без IT-отдела

Ставится на обычный компьютер, работает без интернета, копии базы делает сама.

Как разработчик

Устройство программы «План-факт»

Один сервер в сети предприятия, браузер на любом устройстве. Вся логика проверок и расчётов на сервере, поэтому она одна для интерфейса и для автотестов.

  • Сервер и расчёты — Python, интерфейс — JavaScript без фреймворков
  • База SQLite с пошаговыми миграциями: обновление не теряет данные
  • Лицензии с цифровой подписью Ed25519, привязка к компьютеру
  • Название и модули программы заданы в одном месте
Инженерные практики

Что делает программу надёжной

314 автотестов

Запускаются перед каждым выпуском: права, расчёты, проверки сервера, миграции, обновления.

Сборка на GitHub Actions

Один запуск собирает установщик Windows и архив для Mac, проверяет запуск сервера и публикует релиз.

Защита данных

Ежедневные копии базы, точки восстановления, корзина на 30 дней, копия перед каждым обновлением.

Отмена действий

Последние 20 действий отменяются; если запись уже изменил другой пользователь, программа спросит.

Проверка обновлений

Программа сама узнаёт о новой версии и показывает список изменений до установки.

Документация в комплекте

Руководство администратора, памятки для ролей, справка «?» на каждом экране, окно «Что нового».
